About This App

Chart Converter · Codename Engine → V-Slice

Function
Converts a Codename Engine chart (.json) into V-Slice chart format, including camera events, screen effects, and lyrics conversion.
Output format
V-Slice Chart Format 2.0.0
Supported input
Chart (.json), additional Events (.json), HScript (.hsc/.hscript/.txt)
Settings
Per-effect multipliers and per-event active/inactive toggles, all in the Advanced Setting tab.
Note Types
Detected automatically once a chart file is selected. Turn off any notetype in the Advanced Setting tab, and choose whether those notes get removed entirely or kept as plain Normal notes.
Scroll Speed Camera Movement Stage Zoom Bloom Saturation Vignette Cinematic Bars HUD Alpha Lyrics HScript
All conversion happens directly on your device in the browser — no files are ever uploaded to any server.
